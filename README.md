# ISBN 추출기 (extract_isbn)

BookOasis 메타데이터 플러그인. EPUB / PDF / TXT 파일의 **앞부분과 뒷부분**(판권지가 있을 만한 구간)만 훑어서 ISBN을 찾아냅니다. 정규식으로 먼저 시도하고, 애매하거나 못 찾았을 때만 LLM(Gemini 또는 LiteLLM 호환 프록시)에게 판독을 맡깁니다.

- Plugin ID: `extract_isbn`
- 현재 버전: `1.2.1` (`VERSION` 파일 참고)
- 계약: `search` / `apply` (필수), `get_dashboard_data` / `dashboard_widget` (선택)

---

## 설치

1. 이 저장소의 파일 4개(`extract_isbn.py`, `utils_extract_isbn.py`, `__init__.py`, `VERSION`)를 BookOasis 서버의 `plugins/metadata/extract_isbn/` 폴더에 그대로 복사합니다.
2. `pip install pymupdf` (PDF 지원용 — 미설치 시 PDF 검색은 원인이 명시된 에러 메시지와 함께 실패합니다)
3. 서버 재시작 후 환경설정 > 플러그인 설정에서 **ISBN 추출기**를 활성화합니다.

### 자동 업데이트

`update_manifest`가 이 GitHub 저장소(`yume-script/extract_isbn`, `main` 브랜치, 루트 경로)를 가리키도록 설정되어 있습니다. 환경설정 화면의 샘플 업데이트 버튼으로 `현재 버전 < GitHub 버전`일 때만 갱신됩니다.

---

## 사용 방법

1. 도서 상세 화면에서 **메타데이터 검색** 모달을 엽니다.
2. 제공자 드롭다운에서 **ISBN 추출기**를 선택합니다.
3. 검색어에 도서 제목(또는 제목의 일부)을 입력하고 검색합니다.
4. 결과 카드 제목에 `[ISBN: ...]` 형태로 추출된 값이 표시됩니다 — 이를 적용하면 **ISBN 필드만** 갱신되고, 제목/저자/출판사/표지/설명은 변경되지 않습니다.

> ⚠️ 코어의 `search()` 계약은 대상 도서의 `book_id`를 넘겨주지 않습니다. 그래서 이 플러그인은 검색어(제목)로 DB에서 도서를 추정해서 찾습니다. 검색어와 제목이 정확히 일치하지 않으면 결과 카드에 `⚠️ 유사한 도서로 추정했습니다` 경고와 함께 실제 대상 파일 경로가 표시되니, **적용 전 반드시 확인**하세요.

## 동작 원리

### 1. 대상 도서 찾기 (`_find_book`)
1. 제목 완전 일치
2. 실패 시 파일 경로 부분 일치(`LIKE`)
3. 실패 시 제목 단어 조합(앞 2단어) 유사 검색

완전 일치가 아닌 경우 결과에 경고가 표시됩니다.

### 2. ISBN 스캔 범위
- **EPUB**: 먼저 `<dc:identifier>` 메타데이터 태그 확인 → 없으면 spine(챕터) 앞 5개 + 뒤 5개 스캔
- **PDF**: 앞 5페이지 + 뒤 5페이지 스캔
- **TXT**: 파일 앞 8000바이트 + 뒤 8000바이트 스캔 (작은 파일은 전체를 한 번에 읽음)

이미지 전용(스캔본) 파일은 표본 텍스트 추출 결과로 조기에 걸러내 불필요한 처리를 하지 않습니다.

### 3. 로컬 정규식 매칭과 신뢰도
- ISBN-13(978/979 접두사 + 체크디지트)은 접두사 자체가 구체적이라 발견 즉시 확정 채택합니다.
- ISBN-10은 체크디지트만으로는 전화번호·일련번호 등과 우연히 겹칠 수 있어(약 1/11 확률), 매치 주변 30자 이내에 `ISBN`이라는 문구가 있는지로 **신뢰(confident) / 낮은 신뢰(weak)**를 구분합니다.
  - 신뢰 후보가 있으면 바로 채택 (`LOCAL`)
  - 신뢰 후보가 없고 weak 후보만 있는데 AI 설정이 되어 있으면, weak 값을 바로 쓰지 않고 **AI로 한 번 교차검증**합니다.
  - AI 미설정이거나 AI도 실패하면 weak 후보로 최종 폴백합니다 (`LOCAL_WEAK`, 결과 카드에 경고 문구 포함).

### 4. AI 보조 판독 (`extract_isbn_via_llm`)
- 로컬 매칭이 불확실할 때만 호출됩니다(비용 절감).
- 프롬프트에 "본문에 실제로 있는 값만 답하고, 없으면 추측하지 말고 빈 문자열을 반환하라"를 명시해 모델이 사전지식으로 그럴듯한 ISBN을 지어내는 것을 방지합니다.
- Gemini 다이렉트 모드와 LiteLLM(OpenAI 호환) 모드를 모두 지원합니다.

### 5. 재추출 방지 (캐싱)
검색 대상 도서에 이미 유효한 ISBN이 저장되어 있으면, 파일을 다시 읽거나 AI를 호출하지 않고 기존 값을 그대로 보여줍니다. 강제로 다시 추출하려면 해당 도서의 ISBN 값을 비운 뒤 재검색하세요.

## 단계별 로그

모든 추출 시도는 `StepLogger`가 각 단계(도서 매칭 → 파일 확인 → 메타데이터/본문 스캔 → 신뢰도 판정 → AI 호출 여부/결과)를 순서대로 기록합니다.

- 서버 콘솔(stderr)에 `[ISBN추출] ...` 형식으로 실시간 출력됩니다.
- 검색 결과 카드의 설명(`summary`/`description`)에도 `[처리 단계 로그]` 섹션으로 그대로 붙어서, **성공/실패와 무관하게** UI에서 바로 확인할 수 있습니다.
- 판권지 원문 텍스트 자체는 로그에 남기지 않고, 파일명/구간 번호/개수/성공 여부 같은 메타 정보만 기록합니다.

## 설정 항목 (`config_schema`)

| 키 | 설명 | 필수 |
| --- | --- | --- |
| `GEMINI_API_KEY` | Gemini 또는 LiteLLM 프록시용 API 키 | 아니오 |
| `LITELLM_ENDPOINT` | LiteLLM(OpenAI 호환) 프록시 주소. 비워두면 Gemini 공식 API를 직접 호출 | 아니오 |
| `LITELLM_MODEL` | LiteLLM 모드에서 사용할 모델명 (예: `gemini/gemini-3.5-flash-lite`) | 아니오 |
| `GEMINI_MODEL` | Gemini 다이렉트 모드 모델명 (기본값: `gemini-3.5-flash-lite`) | 아니오 |
| `REQUEST_TIMEOUT_SEC` | LLM 요청 타임아웃(초, 기본 15) | 아니오 |
| `DASHBOARD_LIMIT` | 대시보드 "ISBN 미보유 도서" 위젯에 표시할 최대 개수 (기본 10) | 아니오 |

API 키/엔드포인트를 모두 비워두면 로컬 정규식 매칭만 사용합니다(무료, 다만 문맥 미확인 ISBN-10 오탐 가능성은 남음).

## 대시보드 위젯

`ISBN 미보유 도서` 위젯이 공통 데스크에 노출되며, `isbn` 컬럼이 비어있는 최근 도서 목록을 보여줍니다. (현재는 목록 조회만 지원하며, 일괄 추출 실행 버튼은 아직 없습니다 — 코어에 위젯에서 개별 도서 액션을 트리거하는 표준 방법이 추가되면 확장 예정.)

## 알려진 제한사항

- `search()` 계약이 `book_id`를 넘기지 않아 도서 매칭이 완전 일치가 아닐 경우 fuzzy 검색에 의존합니다. 제목이 비슷한 도서가 여러 권 있으면 잘못된 파일을 열 수 있으니 결과 카드의 경고/파일 경로를 꼭 확인하세요.
- ISBN-10은 체크디지트 통과만으로는 100% 신뢰할 수 없어 문맥 확인 로직을 두었지만, 여전히 완벽하지 않습니다. 가능하면 ISBN-13이 있는 도서를 우선 신뢰하세요.
- 대량 도서에 대한 일괄 추출 UI는 아직 없고, 도서별로 개별 검색해야 합니다.
- EPUB/PDF/TXT 외 포맷(예: MOBI, AZW3)은 지원하지 않습니다.
